ИСПОЛЬЗОВАНИЕ:

Откройте терминал и введите следующие команды:

git clone http://github.com/Glebas4/NTO_2026 #Клонирование репозитория

cd NTO_2026 #Открыть директорию с решением

chmod +x setup.sh #Сделать скрипт настройки исполняемым

./setup.sh  #Запустить настройку


После фразы "Setup was completed" можете запустить Gazebo.

Затем перейдите по http://localhost/clover/clover.html в браузере.

В терминале(в том,который запустили в начале) пропишите python3 genmap.py 

После завершения генерации,можете запускать миссию - python3 flight.py 



КРАТКОЕ ОПИСАНИЕ:

python3 genmap.py - генерация труб (Без аргументов)

python3 genmap.py clear - очистка карты (При запуске можно указать любые аргументы, например python3 genmap.py abrakadabra)


python3 flight.py - запуск полетной миссии


http://localhost/clover/clover.html - WEB приложение 




ПРИМЕЧАНИЯ:

1)bash скрипт будет взаимодейстовать с сетью(скачивание пакета image_geometry)

2)После генерации труб создается файл log.txt, этот файл нужен ТОЛЬКО для отрисовывания основной трубы на 2D aruco_map карте(WEB приложение),
алгоритму он НЕ ПОМОГАЕТ

3)Во время работы flight.py могут вылазить ошибки tf, но если дрон продолжает лететь и распознавать врезки - игнорируйте их,в противном случае
перезапустите код. Если это не помогло, полностью перезапустите Gazebo. Координаты врезок публикуются в /tubes в виде PoseAraray msg

4)В WEB приложении отображена карта с врезками и изображение с камеры,на котором синим цветом выделяется основная труба,
врезки выделяются зелеными прямоугольниками,направление движения коптера - красный отрезок.
Врезки на карте отображены красными точками,также выводится список координат врезок

5)Если в WEB приложении топики не грузятся,просто пообновляйте страницу(Firefox на вирт машине может тупить,если выделено мало ресурсов)

6)Генерация карты работает через ROS сервисы Gazebo, то есть генерацию запускать при функционирующем симуляторе

7)Команда не несет ответственность за ошибки в терминале Gazebo, мешающие функционировать системе(poll timeout, ros.mavros.time, etc), при их возникновении перезапустите симулятор

8)Ссылка на видео,содержащее прохождение миссии, находится в файле VIDEO_LINK.txt

9)На видео может показаться,что изгиб трубы создается в одной и той же точке,но это НЕ ТАК!(см. файл genmap.py,там нет фиксированных координат,
за исключением начальной точки трубы)
